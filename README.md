# Nancy — The Stress-Test Council

A Claude Code skill that pulls you out of agreement mode.

## What it does

`/nancy [anything]` activates a council of five adversarial personas who attack your idea, plan, pitch, or Claude's own output from different angles:

| Persona | Job |
|---|---|
| 🔪 The Contrarian | Finds the single most likely failure mode |
| 🚀 The Expansionist | Finds the 10x bigger version of the idea |
| 🧱 The First Principles Thinker | Strips assumptions, rebuilds from logic |
| 🔍 The Deep Researcher | Searches for real market data |
| 🛒 The Buyer | Role-plays as the real target customer |

Then **The Judge** delivers a verdict: `GREEN LIGHT / RESHAPE / KILL` — plus a 48-hour test you can run today for free.

## Install

```bash
claude plugin install creative-architect/nancy
```

## Usage

```
/nancy [your idea, plan, pitch, or paste Claude's output]
```

Works on everything: business ideas, pricing models, website copy, code architecture, pitch decks, brand names, marketing campaigns.

## Examples

```
/nancy my GHL snapshot business targeting HVAC companies at $497/mo
/nancy the website we just built
/nancy [paste your pitch deck]
```
